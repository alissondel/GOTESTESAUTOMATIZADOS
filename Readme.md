## Installation

bash
# Instalacao do pacote Selenium WebDriver
$ dotnet add package Selenium.WebDriver

# Instalacao do pacote Configuration
$ dotnet add package Microsoft.Extensions.Configuration --version 10.0.2

# Instalacao do pacote Configuration.Binder
$ dotnet add package Microsoft.Extensions.Configuration.Binder --version 10.0.0

# Instalacao do pacote Configuration.Json
$ dotnet add package Microsoft.Extensions.Configuration.Json --version 10.0.2

# Instalacao do pacote WaitHelpers
$ dotnet add package DotNetSeleniumExtras.WaitHelpers
